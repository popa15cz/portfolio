As a kid, I've always wanted to build my own home cockpit. It started as a simple, universal flight simulation setup and gradually became more complex as I added new panels and hardware, eventually reaching the setup shown in the "OLD HOME COCKPIT" picture.

In this setup, I used Saitek FIPs, which require their own gauges - software that controls what is displayed on each screen. I learned how they worked and developed many of these gauges entirely myself.

Later, I decided to completely rebuild the cockpit and make it specifically for the Airbus A320. I learned to cut the wooden structure myself using a CNC milling machine and assembled it using screws and glue.

I also see the cockpit as preparation for my future aviation career. While it is not a substitute for real flight training, building and operating it helps me become familiar with the A320 environment and systems, with the long-term goal of eventually completing an A320 type rating.

For me, the cockpit is more than a simulator. It is a long-term technical project that brings together many of my interests - aviation, programming, hardware and engineering - while constantly giving me something new to learn.
